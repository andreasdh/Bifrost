Entalpi og entropi i samspill

M2+(aq) + 6 L(aq) → [ML6]2+(aq)

Fritt metallion og seks frie ligander i løsning — høy entropi i systemet.
ΔSsystem
0
ΔSomgivelser
0
ΔSunivers
0

Kompleksdannelsen er entropisk ugunstig i systemet — seks frie ligander mister bevegelsesfrihet når de bindes til metallionet, så ΔSsystem < 0. Reaksjonen er likevel eksoterm: varmen som frigjøres øker bevegelsen til molekylene i omgivelsene, så ΔSomgivelser > 0 — og mer enn kompenserer for tapet i systemet. Summen ΔSunivers forblir positiv, i tråd med termodynamikkens andre lov.
