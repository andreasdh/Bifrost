Hvor nær reversibel grense er du?
—
Konvensjon: w (arbeid utført på systemet) = −∫pextdV (IUPAC/Atkins). Denne simuleringen viser womg = −w, altså arbeidet gassen utfører på omgivelsene — positivt ved ekspansjon, negativt ved kompresjon. Ved N = 1 forutsettes at pext holdes konstant lik sluttrykket for det trinnet; for N → ∞ nærmer summen seg integralet, og prosessen blir reversibel.
